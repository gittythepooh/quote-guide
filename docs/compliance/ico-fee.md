# ICO data protection fee

Most organisations that process personal data must register with the ICO and pay a yearly fee unless an exemption applies. Reported fee tiers have been in the tens of pounds for the smallest organisations and about £2,900 at the top, but **amounts and tiers change, and sources disagree. Use the ICO's own tool.**

## To do
1. Open the ICO "Do I need to pay?" self-assessment on ico.org.uk.
2. Answer as the controller named in the privacy notice. Note the date and result in this file.
3. If you must pay, register and pay (direct debit is usually cheaper) and put the registration number in your records.
4. Re-check if the project changes (for example you form a company, take on staff, or add accounts or email).

Exemptions are narrow (for example some not-for-profit, staff administration and marketing-only purposes). Running a public website that stores report data is unlikely to fit them automatically. Do not assume.
