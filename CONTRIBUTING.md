# Contributing

Fog Off is source-available (PolyForm Noncommercial 1.0.0) so anyone can check how it works.

- **Found a mistake or a doubtful number?** Please open an issue. Say which page and what looks wrong.
- **Found a security problem?** Email hello@fogoff.wtf. Please do not open a public issue.
- **Code changes:** not accepted for now. Issues and corrections are welcome.
- **Using the code:** personal, research, education and non-profit use is fine. Commercial use needs permission. See `LICENSE` and `CONTENT-LICENSE.md`.
